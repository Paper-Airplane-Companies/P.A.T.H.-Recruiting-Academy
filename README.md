# P.A.T.H. Recruiting Academy

Better Recruiter Conversations. Better Hiring Outcomes.

P.A.T.H. Recruiting Academy is a recruiting methodology and training platform built by Brandon Labonte. It is designed to help recruiters, talent acquisition teams, and hiring leaders run better conversations with candidates, improve phone screens, strengthen discovery, and create more consistent hiring outcomes.

This repository hosts the public-facing website for P.A.T.H. Recruiting Academy.

## What This Site Covers

The site introduces the P.A.T.H. framework and the philosophy behind it.

- Home. Overview of the framework and what P.A.T.H. is built to solve.
- About. Background on the founder and the experience that shaped the methodology.
- Framework. How the P.A.T.H. model is structured and how it shows up in real recruiting conversations.
- Services. How the framework can be delivered through training, implementation, and support.
- Contact. The entry point for inquiries, framework overviews, and team conversations.

## The Core Idea

P.A.T.H. is built on one belief. Better hiring starts with better conversations.

The framework moves recruiters away from early job pitching and surface-level qualification, and toward discovery-driven conversations that uncover what a candidate actually wants, what is not working in their current role, and whether the opportunity is a real fit. It is designed to be coachable, repeatable, and used in real recruiting work, not parked in a slide deck.

## Founder

Brandon Labonte is an HR and recruiting leader with experience across consulting, high-volume recruiting, operational hiring, and senior HR leadership. He has recruited and hired for roles spanning executive leadership down to skilled trades and frontline operational positions. P.A.T.H. was built from patterns observed across that range of hiring experience.
